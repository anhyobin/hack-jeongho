## 같은 시간에 다른 참가자도 파고 있었어요

랭킹에 이쪽에서 올리지 않은 기록이 섞여 있어요.

| 시각 | 기록 | 비고 |
|---|---|---|
| 21:46:15 | `핵정호 / 1004점 / rows 1004 / hedgehog` | **이쪽 기록이 아님.** 21:46:12 에 올린 1500점 직후 3초 |
| 21:55:15 | `미안해요정호님 / 2000점 / rows 2000 / peccy` | **이쪽 기록이 아님.** 현재 1위 |

`rows` 값이 딱 떨어지고 점수가 사람 기록의 5배라서, 다른 참가자도 같은 API 경로를 찾아낸 것으로 보여요.
닉네임에 소유권이 없어서 `핵정호` 라는 이름을 다른 사람이 그대로 쓸 수도 있었어요.

## 남은 선택지

- 더 높은 점수: 점수 × 0.24초만큼 기다리면 돼요. 3000점 ≈ 12분, 10000점 ≈ 41분
- 지우기: 공개 API에 삭제 경로가 없어서 이미 올라간 기록(440점 등)은 지울 수 없어요
