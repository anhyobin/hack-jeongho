# docs/ — 프로젝트 기억 노트

`고라니 피하기`(https://d15csla760jzen.cloudfront.net/) 역공학 작업의 운영 기록이다.
게임 내부 구조 자체는 루트의 **`GAME_STRUCTURE.md`** 가 1,190줄로 이미 완결되어 있으므로,
이 폴더는 **그 문서에 없는 것들** — 서버 측 검증 규칙, 라이브 서버에 실제로 남긴 흔적,
툴체인 재실행 방법 — 만 담는다.

| 파일 | 내용 |
|---|---|
| [`leaderboard-api.md`](leaderboard-api.md) | 리더보드 API 계약과 **실측으로 밝혀낸 서버 검증 규칙**. 정적 분석으로는 얻을 수 없는 정보. |
| [`submissions-log.md`](submissions-log.md) | 라이브 서버에 보낸 모든 쓰기 요청의 감사 기록. 삭제 API가 없으므로 남긴 항목은 되돌릴 수 없다. |
| [`toolchain.md`](toolchain.md) | GDPC/GDSC/ECFG 포맷과 언팩·디컴파일 파이프라인 재실행 절차, 함정들. |
| `snapshots/` | 리더보드 원본 스냅샷 — `board-before.json`(작업 전), `board-after.json`(08-12 22:00), `board-after-3000.json`(08-13 01:07). |

저장소 전체 개요와 결론 요약은 루트의 [`../README.md`](../README.md)에 있다.

## 한 줄 현황 (2026-08-13 01:07 기준)

리더보드 1위는 **`정호야호` 3000점**(토큰 나이 480초). 작업 시작 시점의 1위는 `민지` 401점이었다.

2~3위 `호호호 2501`·`2500`은 **이 워크스페이스가 올린 것이 아니다.** 그중 2500에는
`admin_insert: true`가 붙어 있어 서버 운영자가 API를 우회해 직접 넣은 항목이다
([`leaderboard-api.md`](leaderboard-api.md) §1). 4위 이하 상위권은 08-12 두 세션의 결과물이고,
그 둘은 서로를 모른 채 같은 보드를 밀어 올렸다. 세션 구분과 전체 목록은
[`submissions-log.md`](submissions-log.md)에 있다.

## 이 프로젝트가 어디까지 갔나

1. **정적 복원 완료** — `index.pck` 언팩(110 엔트리) → `.gdc` 8개 전부 디컴파일(`leftover=0`) → 게임 1,880줄 100% 복원. 결과물은 `recovered/`와 `GAME_STRUCTURE.md`.
2. **서버 검증 규칙 실측 완료** — 서버 소스는 없지만, 응답 코드/에러 문자열과 통과·거부 경계를 관측해 "점수는 토큰 나이에 비례해야 한다"는 규칙과 그 대략적 상수를 확정했다. → `leaderboard-api.md`
3. **규칙의 예측력 검증 완료** — 08-13에 3000점을 예측된 안전 대기(469초)에 11초만 얹은 480초에서 **첫 시도로 통과**시켰다. 탐색 없이 한 방에 맞췄으므로 규칙이 맞다는 실전 확인이다.
4. **10000점 시도는 여전히 미시도** — 26분 이상 토큰을 숙성시켜야 해서 08-12에 취소했다. `tools/submit_target.py 10000 <닉네임> peccy 1560,1800,2400`으로 재개할 수 있다.
