# 프록시 로그 — 실서버에 실제로 나간 요청의 정사

`tools/local_proxy.py`가 남긴 중계 로그다. **게임 쪽 로그와 어긋나면 이쪽이 맞다.**

08-17에 이 구분이 하루를 갈랐다. 게임은 `[search] 청크 N 무응답/거부`를 찍는데 여기에는
`POST /api/chunk`가 **한 건도 없는** 경우가 있었다 — 요청이 나가지 않았다는 뜻이고,
"서버가 거부했다"가 아니다(`docs/autopilot.md` §13.1).

| 파일 | 무엇의 증거인가 |
|---|---|
| `live_08-16_1953.log` | **진짜 403.** 청크 3이 `-> 403`으로 거부됐다(유령이 아니다) |
| `live_08-17_0824_run1.log` | 청크 2~17을 415행까지 **16건 전부 발급**, 거부 0건. 08-16에 거부됐던 (청크 8@190, 9@215, 10@240)이 여기서 전부 발급된다 |
| `live_08-17_0832_run3.log` | **유령 거부의 증거.** 게임은 "청크 5 거부"를 찍었는데 여기엔 청크 2·3·4만 있다. 이 파일 때문에 "결정적 대조 실험" 보고를 정정했다 |
| `live_08-17_0902_run5.log` | 갇힘 종료(25회차) 정상 발동, 제출 없음 |
| `live_08-17_2106_run6_SUCCESS.log` | **`야호정호 600점` 등록** (`POST /api/scores -> 200 ok rank 1`) |
| `live_08-17_2125_700attempts.log` | 700점 실패 3회. 그중 하나가 **621점/561행** — `sfloor`를 660으로 올려 잡아 버린 기록 |
| `live_08-17_2146_run700_SUCCESS.log` | **`정호돌격 700점` 등록**, 청크 27까지 발급 |
| `live_08-17_2246_1000attempts.log` | 1000점 시도 2회 (633점/561행, 423점/391행) |

읽는 법 — 거부를 셀 때는 `-> 403`을 세고, 요청 수를 셀 때는 `POST /api/chunk`를 센다.

```bash
grep -c 'POST /api/chunk' live_*.log     # 실제로 나간 요청
grep -c '\-> 403'         live_*.log     # 실제 거부
grep -A1 'POST /api/scores' live_*.log   # 제출과 그 응답
```

토큰 문자열이 남아 있지만 모두 1회용이고 이미 소비됐다.
